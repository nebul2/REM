## Available Pages

### 1. Main Exploration Dashboard
**URL:** http://localhost:7001/

**Features:**
- Experiment A/B selection and comparison
- Time range controls (15m, 1h, 6h, 24h, custom)
- Aggregation intervals
- Statistical toggles (mean/median/total/average)
- Side-by-side Chart.js visualizations
- Energy statistics display
- Timeline annotations
- Snapshot saving

### 2. Group Management
**URL:** http://localhost:7001/manage

**Features:**
- Create/edit/delete device groups (experiments)
- Checkbox interface for device selection
- Simple UI for non-technical users

### 3. Snapshot Gallery
**URL:** http://localhost:7001/gallery

**Features:**
- View all saved snapshots
- Filter by experiment
- Search functionality
- Detailed snapshot view

---

## API Endpoints

- `/api/devices` - Get available devices
- `/api/groups` - Manage device groups
- `/api/experiments` - Manage experiments (uses groups)
- `/api/data/power` - Query power consumption data
- `/api/annotations` - Manage timeline annotations
- `/api/snapshots` - Manage snapshots
