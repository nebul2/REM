# GoS Logo Specifications

## Description
- **Shape**: Circular with scalloped/gear-like outer border (16 rounded lobes)
- **Colors**: 
  - Outer border: Muted/sage green with darker green outline
  - Inner circle: Solid muted green
  - Inner elements: White
- **Design**: Stylized white "G", "1" (or "I"), and "S" intertwined within green circle

## Color Palette
- **Primary Green**: Muted/sage green (outer border and background)
- **Outline Green**: Darker green (border outline)
- **White**: For letter/number elements

## Usage
- Header logo
- Favicon
- Branding throughout UI

## Implementation Notes
- Use green as primary theme color
- White for text/contrast
- Circular logo shape
- Professional, clean aesthetic
