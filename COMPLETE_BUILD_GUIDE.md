## Features Being Built

### ✅ Core Functionality
1. **Experiment/Group Management** - Create, edit, delete experiments
2. **Data Visualization** - Chart.js time-series charts
3. **A/B Comparison** - Side-by-side experiment comparison
4. **Statistical Analysis** - Mean, median, min, max toggles
5. **Energy Calculations** - Total kWh, average W over time
6. **Timeline Annotations** - Mark and describe test points
7. **Snapshot Gallery** - Save, archive, search charts
8. **GoS Branding** - Logo, colors, favicon
