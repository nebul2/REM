# Test Scripts

These scripts were used during development and testing. They are not required for normal operation.

- `test_polling_rate.sh` - Testing different polling intervals
- `test_polling_intervals.sh` - Automated polling interval testing
- `test_intervals_automated.sh` - Automated interval testing
- `CHECK_NULL_DATA.sh` - Checking for null data in database
- `migrate_data.sh` - Legacy data migration script
- `create-auth.sh` - Helper script for creating authentication
