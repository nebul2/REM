# Build Confirmation - GOS REM Data Exploration UI

## ✅ I Understand Your Requirements

### Architecture
- **Collector** = Data logger only (unchanged)
- **New UI** = Full exploration tool (reads from InfluxDB)

### Core Features Required

1. **Experiment/Group Management**
   - Filter by device groups
   - A/B testing (compare two groups)
   - Re-run experiments (change membership)

2. **Data Visualization**
   - Time-series power charts
   - All devices in experiment shown
   - Statistical overlays (mean/median toggle)
   - Aggregate lines (total + average)

3. **Energy Calculations**
   - Total energy over time (kWh)
   - Average energy (W)
   - Per-device and aggregate

4. **Timeline Annotations**
   - Mark specific test points
   - Rich descriptions
   - Visible on charts

5. **Snapshot & Archive**
   - Save chart snapshots
   - Gallery view
   - Search/filter
   - Recall historic experiments

6. **GoS Branding**
   - Logo integration
   - Green color scheme
   - Favicon
