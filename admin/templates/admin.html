Data Export & Import

Export your complete GOS REM database for backup or migration to a new instance. Import a previously exported backup to restore all data, experiments, groups, and snapshots.

Export Database

Export all data including:

  • TimescaleDB data - All power measurements and time-series data
  • Experiments - All experiment definitions and configurations
  • Device Groups - All device group definitions
  • Snapshots - All snapshot images and metadata

Note: The export may take several minutes for large databases. The download will start automatically when ready.

Import Database

Import a previously exported backup file to restore all data.

⚠️ Warning Importing will replace all existing data, experiments, groups, and snapshots with the imported data. This action cannot be undone. Make sure to export your current data first if you want to keep it.

The import file should be a ZIP file created by the Export function, containing:

  • PostgreSQL database dump
  • Experiments JSON file
  • Device groups JSON file
  • Snapshots directory
  • Metadata/manifest file
